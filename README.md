# Макромодель транспорта Долгопрудного

Учебный проект курса «Транспорт большого города». Наша задача — оценить автомобильные потоки в континентальном Долгопрудном с 07:00 до 09:00 по четырём получасам и выгрузить результат для 30 направлений замера.

## Начать здесь

1. Склонируйте репозиторий и откройте [стартовую страницу](Начать_здесь.html) или [карту районирования](project_boundary_map.html) **локально в браузере**. Карта использует подложку OpenStreetMap и требует интернет.
2. Возьмите задачу из [чек-листа на пять шагов](Чек-лист_макромодели.md). Там указано, какой файл использовать, что из него взять и что передать команде.
3. Работайте в отдельной ветке, например `network`, `zone-connections` или `demand`. Готовые изменения отправляйте pull request в `main`.

## Что уже готово

| Материал | Что внутри |
|---|---|
| [Основное районирование](zones_primary.geojson) | Семь внутренних зон. Парк и Центральный объединены. МФТИ и студгородок выделены в Z08. |
| [Дорожный граф](osm_data/roads.graphml) и [слои для QGIS](osm_data/roads.gpkg) | Направленная сеть для выбора маршрутов. Снимки OSM и здания лежат в `osm_data/`. |
| Входные файлы курса | Получите `area.csv`, `points.csv`, `calibration.csv` и `flows_template.csv` из материалов задания и положите рядом с `model.py`. |
| [Ядро модели](model.py) и [инструкция](Запуск_MVP.md) | Из входных данных код строит OD-матрицы, ищет равновесие и записывает `flows.csv`. Проверено на условных сетях. |

**Городского прогноза пока нет.** Ближайший результат — первый `model_input.json` и воспроизводимый `flows.csv`.

## Что делать первым

| Кто | С чего начать | Что передать |
|---|---|---|
| Сеть | Открыть `roads.gpkg` и `points.csv`. Найти направленные рёбра для P02A, P02B, P08A и P14B. Затем разобрать остальные точки и задать рёбрам время проезда и пропускную способность. | Блоки `edges` и `point_edges`. |
| Районирование | Наложить `zones_primary.geojson` на граф. Отметить реальные подъезды к Водникам, ДНПП и МФТИ. Проверить, где три внешних коридора пересекают `area.csv`. | Блок `zones` с узлами отправления и прибытия. |
| Спрос | Взять здания и места назначения из `osm_data/features.geojson`, распределить по семи зонам и отдельно записать допущения для внешних потоков. `calibration.csv` использовать для проверки, учитывая расположение камер. | Блок `periods` и таблицу источников и допущений. |
| Сборка | Собрать четыре блока по [формату входа](Запуск_MVP.md), запустить модель и сравнить первый прогноз с камерами. | `model_input.json`, `flows.csv` и таблицу сравнения. |

Спрос задаём в **машинах за получас**, результат записываем в **авто/ч**. Для сравнения с открытым часовым замером берём среднее двух получасовых интенсивностей.

## Запуск

Сначала скопируйте четыре входных CSV из материалов курса в корень репозитория. Затем соберите `model_input.json` и запустите:

```powershell
python model.py model_input.json
```

Ядро использует стандартную библиотеку Python. Для пересборки графа и карт нужны зависимости из [инструкции по запуску](Запуск_MVP.md). Данные OpenStreetMap © [участники OpenStreetMap](https://www.openstreetmap.org/copyright), ODbL.
