# Макромодель транспорта Долгопрудного

Учебный проект курса «Транспорт большого города». Цель проекта — построить
автомобильную макромодель континентальной части Долгопрудного для буднего утра
с 07:00 до 09:00 по четырём получасовым интервалам и рассчитать интенсивности
движения для 30 направлений из материалов курса.

## Текущий статус

В репозитории уже находятся исходные данные курса, снимок OpenStreetMap,
направленный дорожный граф, черновое районирование, предварительная модель
спроса, предварительная оценка веса внешних ворот по населению соседних территорий и вычислительное ядро с гравитационной OD-моделью, BPR и методом
Франка—Вульфа.

Полный городской расчёт пока не собран: отсутствуют подключения зон,
привязки направлений измерений и `data/processed/model_input.json`. Поэтому
итоговый `outputs/flows.csv` ещё не получен.

## Структура проекта

```text
src/                    код модели и подготовки данных
data/input/             четыре входных CSV из материалов курса
data/osm/               снимки OSM, объекты и дорожный граф
data/processed/         зоны и предварительные данные спроса
data/hse_data           данные по населению в ближайших муниципалитетах
notebooks/              исследовательский ноутбук
docs/                   статус проекта и дорожная карта
outputs/                карты и будущий flows.csv
```

В `data/input/` находятся:

- `area.csv` — граница моделируемой территории;
- `points.csv` — 30 направлений проверки в 15 местах;
- `calibration.csv` — открытые часовые замеры;
- `flows_template.csv` — шаблон итоговой выгрузки.

## Быстрый старт

Проект использует Python 3.12 и менеджер зависимостей
[uv](https://docs.astral.sh/uv/).

Установить окружение:

```powershell
uv sync --locked
```

Проверить сохранённый снимок OSM:

```powershell
uv run python -m src.road_network.audit_osm_snapshot data/osm/dolgoprudny_wide.osm
```

Пересчитать предварительные веса зон и спрос:

```powershell
uv run python -m src.transport_demand.zone_stats
uv run python -m src.transport_demand.build_periods
```
Оценить относительный вес внешних ворот по населению (нужен слой ВШЭ в data/hse_data/): открыть notebooks/show_res.ipynb и выполнить ячейки сверху в конце ноутбука после визуализаций

Пересобрать интерактивную карту районирования:

```powershell
uv run python -m src.visualization.view_project_boundary --export-only
```

После появления `data/processed/model_input.json` полный расчёт будет
запускаться командой:

```powershell
uv run python -m src.model data/processed/model_input.json
```

Результат записывается в `outputs/flows.csv` в автомобилях в час.
