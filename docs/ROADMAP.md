# Дорожная карта проекта

Последняя актуализация: 6 ноября 2026 года.

Фактическое состояние реализации описано в
[PROJECT_STATUS.md](PROJECT_STATUS.md). Здесь находятся только будущие задачи
и критерии их завершения.

## Приоритеты

- `P0` — необходимо для первого городского `flows.csv`;
- `P1` — необходимо для калиброванной и объяснимой модели;
- `P2` — улучшение качества данных, модели и анализа.

## Ближайшие задачи: первый городской расчёт

### P0.1. Исправить предварительный спрос

- [ ] Устранить расхождение сумм отправлений и прибытий после округления.
- [ ] Добавить проверку баланса перед сохранением `periods.json`.
- [ ] Явно зафиксировать единицы: машины за получас.
- [ ] Сохранить стартовые допущения рядом с результатом расчёта.

Готово, когда каждый период проходит проверку баланса в `src/model.py`.

### P0.2. Преобразовать OSM-граф в модельные рёбра

- [ ] Назначить устойчивый ID каждому направленному ребру.
- [ ] Определить скорость для рёбер без `maxspeed` по классу `highway`.
- [ ] Разобрать общее и направленное число полос.
- [ ] Выбрать стартовую пропускную способность на полосу.
- [ ] Рассчитать `time_s` и `capacity_vph`.
- [ ] Проверить односторонние дороги и развязки.

Готово, когда сформирован блок `edges`, все значения положительные и
конечные, а основные маршруты существуют в необходимых направлениях.

### P0.3. Подключить внутренние зоны

- [ ] Для каждой из семи зон выбрать узел отправления и узел прибытия.
- [ ] Проверить реальные подъезды к Водникам, ДНПП и МФТИ.
- [ ] Обосновать время примыкания или документировать нулевое значение.
- [ ] Убедиться, что зоны связаны с основной компонентой графа.

### P0.4. Создать внешние ворота

- [ ] Проверить коридор Лихачёвского проспекта у P02.
- [ ] Проверить коридор Московской улицы у Водников около P03.
- [ ] Проверить коридор Долгопрудненского шоссе около P06.
- [ ] Задать для ворот `external: true`.
- [ ] Проверить запрет транзита между внешними воротами.

### P0.5. Привязать направления измерений

- [ ] Для каждого ID от P01A до P15B выбрать направленное ребро.
- [ ] При необходимости объединить параллельные проезжие части одного створа.
- [ ] Отдельно проверить P03, P08 и P10 из-за смещения от геометрии графа.
- [ ] Проверить направления A/B по названию улицы и геометрии движения.

Готово, когда `point_edges` содержит 30 непустых уникальных привязок.

### P0.6. Собрать и запустить `model_input.json`

- [ ] Объединить `edges`, `zones`, `periods` и `point_edges`.
- [ ] Сохранить вход в `data/processed/model_input.json`.
- [ ] Запустить все четыре периода.
- [ ] Проверить сходимость Франка—Вульфа.
- [ ] Проверить 120 значений на конечность и неотрицательность.

Готово, когда воспроизводимо создаётся `outputs/flows.csv` с 30 строками и
четырьмя заполненными периодами.

## Следующий этап: калибровка

### P1.1. Реализовать контроль качества

- [ ] Добавить расчёт GEH.
- [ ] Для часовых замеров усреднять две получасовые интенсивности модели.
- [ ] Сформировать таблицу «ID, час, наблюдение, модель, GEH».
- [ ] Отдельно отслеживать P02A, P02B, P08A и P14B.

### P1.2. Проверить привязки и единицы

- [ ] Устранить ошибки направления и выбора проезжей части.
- [ ] Проверить пересчёт машин за полчаса в автомобили в час.
- [ ] Проверить, что один створ не считает одно ребро дважды.

### P1.3. Калибровать объяснимые параметры

- [ ] Общий масштаб внутреннего спроса.
- [ ] Объёмы внешних ворот.
- [ ] Степень функции тяготения `gamma`.
- [ ] Стартовые пропускные способности.
- [ ] При необходимости параметры BPR.

Этап завершён, когда сохранены исходная и откалиброванная версии, таблица GEH
и объяснение каждого изменённого параметра.

## Правило ведения дорожной карты

После завершения задачи необходимо:

1. отметить соответствующий пункт;
2. перенести фактический результат и ограничения в `PROJECT_STATUS.md`;
3. обновить краткий статус и команды в `README.md`;
4. добавить новые выявленные задачи в подходящий приоритет.

Изменение кода или данных не считается полностью оформленным, пока
`README.md`, `PROJECT_STATUS.md` и `ROADMAP.md` не приведены в соответствие с
репозиторием.
